# PAPER-REVIEW

Kumpulan review paper ilmiah yang disusun secara terstruktur untuk mendukung pembelajaran, analisis literatur, dan penyusunan penelitian tesis.

Repository ini berfokus pada pembahasan penelitian di bidang:

- Computer Vision
- Convolutional Neural Network (CNN)
- Vision Transformer
- Malware Image Classification
- Explainable AI
- Deep Learning

## Daftar Paper

### 2023 - CNN vs Transformer Variants: Malware Classification Using Binary Malware Images

Review ini membahas perbandingan CNN dan beberapa varian Transformer untuk klasifikasi malware berbasis citra biner menggunakan Malimg Dataset.

Topik utama:

- Representasi malware biner menjadi citra grayscale
- Klasifikasi 25 keluarga malware
- Perbandingan CNN, ViT, CCT, dan EANet
- Evaluasi accuracy, precision, recall, F1-score, loss, dan jumlah parameter
- Interpretasi model menggunakan LIME

## Tujuan

Repository ini dibuat untuk menyimpan review secara rapi berdasarkan judul paper. Setiap folder paper dapat berisi:

- `README.md` sebagai review utama;
- folder `IMAGE` untuk gambar, grafik, atau tabel penting;
- sumber paper asli dan tautan publikasi;
- catatan analisis tambahan.
