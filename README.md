## 🔎 Tentang Repository

Koleksi ini dapat digunakan untuk membandingkan pendekatan, dataset, arsitektur model, skenario eksperimen, dan hasil penelitian dari berbagai paper. Ruang lingkupnya bersifat terbuka dan dapat berkembang sesuai kebutuhan kajian.

Topik yang telah atau dapat dibahas meliputi:

- Computer Vision
- Deep Learning
- Convolutional Neural Network (CNN)
- Vision Transformer dan model hybrid
- Natural Language Processing (NLP)
- Malware Analysis dan Cybersecurity
- Dataset, preprocessing, dan evaluasi model
- Explainable Artificial Intelligence (XAI)

## 🗂️ Format Folder

```text
PAPER-REVIEW/
├── README.md
└── TAHUN - Judul Paper/
    ├── README.md
    └── IMAGE/
        ├── gambar-metode.png
        ├── hasil-eksperimen.png
        └── tabel-atau-grafik.png
```

- `README.md` berisi review utama.
- `IMAGE/` berisi gambar, diagram, tabel, atau grafik yang mendukung pembahasan.
- Tautan publikasi dicantumkan pada bagian sumber paper.
- File PDF atau dataset berukuran besar tidak disimpan di repository kecuali diperlukan.

## 📋 Struktur Review Paper

Format review dapat menggunakan urutan berikut:

1. Identitas paper
2. Latar belakang dan tujuan penelitian
3. Dataset dan preprocessing
4. Metode atau arsitektur model
5. Skenario eksperimen
6. Hasil penelitian
7. Kelebihan dan keterbatasan
8. Relevansi terhadap penelitian yang sedang dilakukan
9. Kesimpulan
10. Sumber paper

Struktur tersebut bersifat fleksibel dan dapat disesuaikan dengan karakteristik paper serta tujuan analisis.

## 🤝 Pedoman Kontribusi

Untuk menambahkan review baru:

1. Buat folder dengan format `TAHUN - Judul Paper`.
2. Tambahkan satu file `README.md` sebagai dokumen utama.
3. Simpan gambar pendukung pada folder `IMAGE`.
4. Cantumkan sumber publikasi yang dapat diverifikasi.
5. Tambahkan paper tersebut ke tabel **Daftar Review Paper** di README utama.
